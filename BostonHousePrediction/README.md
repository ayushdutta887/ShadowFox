# Boston House Price Prediction

This project predicts Boston house prices using Machine Learning algorithms and a Streamlit web application.

## Features
- Data preprocessing
- Feature selection
- Model training
- Model evaluation
- Streamlit UI for prediction

## Machine Learning Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Best Model
Random Forest Regressor achieved the best accuracy.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle
