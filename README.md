# ShadowFox 🚀

This repository contains projects completed as part of the ShadowFox Internship Program, focusing on Machine Learning and Data Science applications.

## 📂 Contents

### 1. Boston House Price Prediction
A regression-based machine learning project for predicting house prices using housing-related features.

**Tech Stack:** Python, Pandas, NumPy, Scikit-Learn, Matplotlib

### 2. Loan Approval Prediction
A classification project that predicts loan approval status based on applicant information.

**Tech Stack:** Python, Pandas, Scikit-Learn

## 🛠️ Skills Demonstrated
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- Model Evaluation
- Git & GitHub
